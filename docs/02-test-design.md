# Test Design / Тест-дизайн

## English

Use equivalence partitioning to group inputs expected to behave alike; select representatives from valid and invalid partitions. Use boundary value analysis around minimums, maximums and transition points. Decision tables fit interacting business conditions; state-transition tests fit behavior whose result depends on current state and event.

Exploratory testing combines learning, design and execution. A charter defines scope, risk and timebox; notes preserve observations and follow-up ideas. Pair specification-based techniques with structure-based coverage and experience-based error guessing.

## Русский

Эквивалентное разбиение группирует входы с ожидаемо одинаковым поведением; выбирайте представителей валидных и невалидных классов. Анализ граничных значений проверяет минимумы, максимумы и точки перехода. Таблицы решений подходят для комбинаций условий, state-transition — для поведения, зависящего от текущего состояния и события.

Исследовательское тестирование совмещает обучение, проектирование и выполнение. Charter задаёт scope, риск и timebox, а заметки сохраняют наблюдения и дальнейшие идеи.
