# Practice Cases / Практические задания

## English

1. Design partitions and boundaries for a field accepting integers from 1 through 100.
2. Build a decision table for access based on account state, role and second-factor result.
3. Write API tests for create, duplicate, missing field, unauthorized request and not-found response.
4. Model a login page with semantic locators and no fixed sleeps.
5. Review one flaky test and document its uncontrolled dependency.

## Русский

1. Спроектируйте классы эквивалентности и границы для поля с целыми значениями от 1 до 100.
2. Постройте таблицу решений для доступа по состоянию аккаунта, роли и результату второго фактора.
3. Напишите API-тесты для создания, дубля, пропущенного поля, unauthorized и not found.
4. Смоделируйте login page с семантическими locators без фиксированных sleep.
5. Разберите один flaky-тест и зафиксируйте его неконтролируемую зависимость.
